# Changelog

## 0.0.0

- Flight Map panel: smooth vehicle arrow and trail, QGC style numbered waypoints with the current one highlighted, satellite view, follow mode.
- Message converters for the Map and 3D panels: vehicle position, track and attitude, flown trail, and the Jetson's mission.
- Map: heading arrow, live flight trail, QGC style numbered waypoint dots.
- Flight Status panel: arming, flight mode, VTOL state, control, altitude, speeds, battery, mission progress, failsafe and link status.
